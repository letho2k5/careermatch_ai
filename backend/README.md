# CareerMatch AI backend

NestJS REST API workspace for the CareerMatch AI Flutter application. PostgreSQL integration, environment validation, API modules, and authentication are added in later implementation steps.

## Requirements

- Node.js 24 LTS/current (NestJS 12 requires Node.js 20.19+ or 22.12+; the project was initialized using Node.js 24.22.3).
- npm 11 or compatible.

## Local commands

From this directory:

```powershell
npm install
npm run start:dev
npm run build
npm test
npm run test:e2e
npm run lint
```

The starter root endpoint is only a bootstrap check. It does not represent a completed API or connect to a database.
