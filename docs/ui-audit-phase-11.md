A Flutter Web release build succeeded, but Chrome headless capture failed to render (blank screenshot; Chrome GPU process errors). Therefore the number of valid Flutter-runtime screenshot comparisons is **0**. Do not use the temporary Ahem captures to judge typography, text wrapping, or asset fidelity.
